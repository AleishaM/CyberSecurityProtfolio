# Student Verification System

## Overview

The Student Verification System was developed for St. John's University Public Affairs as part of a competitively selected, cross-functional group project. The system was designed to provide SJU students with secure access to their own records through identity verification and access-control logic.

## Project Details

* **Organization:** St. John's University Public Affairs
* **Project:** Student Verification System
* **Date:** April 2026 – May 2026
* **Project Type:** Group Project
* **Platform:** Oracle APEX

## My Contributions

* Delivered a working identity-verification and access-control system granting SJU students secure access to their own records.
* Tested verification logic against real student-access scenarios to evaluate system security and data integrity.
